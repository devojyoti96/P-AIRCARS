Basic CLI
==========
These are basic CLI for P-AIRCARS pipeline. 

1. The main CLI of P-AIRCARS is ``run-mwa-paircars`` , which is used to run P-AIRCARS pipeline.
 
.. admonition:: Click here to see parameters
   :class: dropdown

   .. program-output:: run-mwa-paircars -h
   
2. To view, measurement set details, use ``show-paircars-ms`` .

.. admonition:: Click here to see parameters
   :class: dropdown

   .. program-output:: show-paircars-ms -h
   
3. To view P-AIRCARS jobs status, use ``show-paircars-status`` .

.. admonition:: Click here to see parameters
   :class: dropdown

   .. program-output:: show-paircars-status -h
   
4. To see jobs logs using local GUI logger, use ``run-mwa-mwalogger`` .

.. admonition:: Click here to see parameters
   :class: dropdown

   .. program-output:: run-mwa-mwalogger -h
   
5. To update P-AIRCARS data, use ``init-paircars-data`` .

.. admonition:: Click here to see parameters
   :class: dropdown

   .. program-output:: init-paircars-setup -h   
   
6. To stop a P-AIRCARS job in between, use ``kill-paircars-job`` .

.. admonition:: Click here to see parameters
   :class: dropdown

   .. program-output:: kill-paircars-job -h

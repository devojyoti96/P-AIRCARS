Install P-AIRCARS
==================
Install P-AIRCARS from PyPI or source code.

Install P-AIRCARS from PyPI
---------------------------

Install latest stable version of P-AIRCARS pipeline, use PyPI as:

.. code-block :: bash

    pip install paircars
    
Install P-AIRCARS from source code
----------------------------------------

Install development version from https://github.com/devojyoti96/P-AIRCARS 

.. code-block :: bash

    git clone https://github.com/devojyoti96/P-AIRCARS.git
   
    cd P-AIRCARS
    
    pip install .

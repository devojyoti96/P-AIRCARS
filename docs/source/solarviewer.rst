View and Analyse Final Products
===============================
To view final fits images and perform analysis, making overlaps or comparing with other wavelength data, we recommend using `SolarViewer <https://pypi.org/project/solarviewer>`_ developed by Soham Dey (NCRA-TIFR, Pune, India). A detailed documentation of using it can be found here: `SolarViewer Documentation <https://github.com/dey-soham/solarviewer?tab=readme-ov-file#-documentation>`_.

.. note::

   Since **SolarViewer** uses different versions of python modules, we recommend installing in different conda environment as per the guidelines in **SolarVoewer** documentation.
